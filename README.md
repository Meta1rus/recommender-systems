# Рекомендательные системы — лабораторные и финальный проект

**Подольский Филипп, магистратура ПМИ, ФМИ ПГНИУ.**
Дисциплина «Рекомендательные системы».

В репозитории — тетрадки курса с решёнными заданиями: текст и структура заданий сохранены, во всех ячейках дописан код,
после каждого вопроса — ответ по числам и графикам этого запуска. Тетрадки выполнены целиком, выводы и графики сохранены
в файлах.

Всё выполнено на Mac с Apple Silicon (M3 Max, GPU через MPS) на исходных данных курса. Данные в репозиторий не входят:
тетрадки скачивают их сами из исходных источников в папку `data/`.

### Что стоит знать о решениях

* **Выбор моделей.** В финальном проекте модель и способ обработки холодных пользователей выбирались по валидации
  (часть `valid_stage_1`), тест использовался только для итоговой оценки. В ДЗ №1, ДЗ №2 и тетрадке по ALS/NCF
  гиперпараметры, как и в формулировках заданий, подбирались по тестовой выборке — в выводах это отмечено.
* **`metric_tests.py`.** В материалах курса этого файла не было, поэтому тесты метрик для ДЗ №1 написаны свои (12 случаев).
* **Исправленные ошибки заготовок** описаны в тетрадках: например, в цикле обучения NCF из шаблона просмотренные айтемы брались как
  `set(DataFrame)` — это множество имён колонок, а не айтемов; метрика `ndcg_metric` из шаблона не чувствительна к порядку выдачи (выводы сделаны по
  стандартному NDCG@k).
* **Итоговый файл рекомендаций** финального проекта (`data/final_outputs/recommendations_tomorrow.csv`, 77 МБ) в
  репозиторий не входит — его создаёт сама тетрадка.

## Как запустить

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

Тетрадки нужно запускать из корня репозитория: данные скачиваются в `data/`, а ДЗ №1 импортирует `metric_tests.py`.

| Тетрадка | Данные (скачиваются автоматически) | Время полного прогона на M3 Max |
|---|---|---|
| `lab1_metrics.ipynb` | не нужны | секунды |
| `lab2_baselines_ease.ipynb` | KION: `interactions.csv`, `items.csv` ([соревнование МТС](https://ods.ai/competitions/competition-recsys-21/data)) | ≈ 1 мин |
| `lab3_matrix_factorization.ipynb` | [MovieLens 1M](https://grouplens.org/datasets/movielens/1m/) | ≈ 22 мин |
| `lab4_als_ncf.ipynb` | KION: `interactions.csv` | ≈ 31 мин |
| `final_project_two_stage.ipynb` | `train.csv`, `test.csv`, `users.csv`, `items.csv` с Google Drive курса (через `gdown`) | ≈ 34 мин |

Для финального проекта есть отладочный режим на 15 % пользователей: `RECSYS_QUICK=1 jupyter lab`.
